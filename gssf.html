Step 01 — Logo

Logo

A stacked GS/SF monogram inside a square frame. The square shape later became the container for sub-brand variants.

Primary — Blue on white
Reverse — Grey on black
Step 02 — Type & Color

Typography and color

Noto Sans for official copy, VCR OSD Mono for accents. The palette is built around blue (#242EC0), with deep indigo, black, and lavender as supporting tones.

Brand guide — type and color
Step 03 — Logo System

Sub-brand variants

The foundation runs multiple programs (GSSC, Academy), so I extended the logo into a system. Each variant uses the same square frame.

Brand guide — logo system
Step 04 — Website

Programs section

The homepage covers the foundation's six programs. I designed a card grid so each program gets equal weight, and so the layout can scale as more programs are added.

Homepage — Programs section
Step 05 — Network Section

Global Network section

A separate section for the foundation's network — mentors, partner universities, and sponsors. Three pillars with a tab system for switching between them.
